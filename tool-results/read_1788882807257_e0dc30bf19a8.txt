  1010→
  1011→5. **Database connection pressure** — Each API call = 1 new DB connection. Server Components share connections during render.
  1012→

  1014→- Static content (members, games, portfolio) → Server Components with SSG (pre-rendered at build time)
  1015→- Dynamic content (guestbook, news, gallery) → ISR (revalidate every 1 min) or Server Components with SSR
  1016→- Interactive forms (guestbook submit, news publish, photo upload) → Client Components + API Routes (still needed for mutations)
